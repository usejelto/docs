# Share a dashboard or widget

Public sharing exposes only the reports you select. Review the content as an anonymous reader before distributing the link.

## Create a public dashboard

1. As an Owner, open **Settings → Sharing**.
2. Create a public-dashboard grant and select the intended report content.
3. Traffic, trends and countries form the default shared view. Select revenue or named goals explicitly when you intend to publish them.
4. Set any fixed supported source, country, browser or device filters and save.
5. Open the generated link in a signed-out browser and confirm its content.

A signed-in viewer receives the same shared view. Authentication does not expand a public link into the private dashboard.

## Embed a widget

Choose Visitor badge, Revenue card, Traffic chart or Activity pill, then copy its generated iframe code into your own site's HTML. The Revenue card requires revenue publication. Widgets default to the previous 30 completed days and adapt to their dimensions and supported theme option.

Use the generated public grant, never a private dashboard URL or an API key. Private dashboards cannot be framed.

## Revoke access

Revoke the grant to stop access through its link or embed. Recheck the public URL afterward. Revocation does not recall screenshots or copies somebody already made of published information.
